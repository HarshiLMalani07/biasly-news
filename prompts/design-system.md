## Implementation requirements

### 1. Font

Load **Poppins** via `next/font/google` in `app/layout.tsx` with `subsets: ["latin"]`, weights `["400", "500", "600", "700"]`, `variable: "--font-poppins"`, and `display: "swap"`. Remove `Geist` and `Geist_Mono` entirely. Apply the variable on `<html>` and keep `antialiased`. Keep the Next 16 `LayoutProps<"/">` prop typing already in the file — do not revert it to a hand-written `children: React.ReactNode` type. Update `metadata` to `title: "biasly — Balanced news coverage, powered by AI"` and a matching description.

`body` must resolve its font from the token, not from a hardcoded stack. Delete the `Arial, Helvetica, sans-serif` rule.

### 2. Token layer — `app/globals.css`

Keep `@import "tailwindcss"`. Define every value below as a CSS custom property and expose it to Tailwind through `@theme inline` so utilities like `bg-surface`, `text-secondary`, `rounded-lg`, `shadow-md` resolve to these exact values. Remove the `--background` / `--foreground` pair and the entire `prefers-color-scheme: dark` block.

**Colors — exact hex, no approximations**

| Token | Hex | Role |
|---|---|---|
| `--color-text-primary` | `#0D0D0F` | primary text, primary button fill |
| `--color-text-secondary` | `#6B7280` | secondary/meta text |
| `--color-surface` | `#F6F6F6` | raised surface |
| `--color-bias-left` | `#B42318` | left bias |
| `--color-bias-center` | `#E5E7EB` | center bias |
| `--color-bias-right` | `#1D4ED8` | right bias |
| `--color-bg-primary` | `#FFFFFF` | page background |
| `--color-bg-secondary` | `#F0F0F0` | secondary background |
| `--color-border` | `#E5E7EB` | borders |
| `--color-divider` | `#E5E7EB` | dividers |

**Typography scale** — size / weight / line-height, all three mandatory:

| Style | Size | Weight | Line height |
|---|---|---|---|
| H1 | 32px | 700 Bold | 1.2 |
| H2 | 24px | 600 SemiBold | 1.3 |
| H3 | 20px | 600 SemiBold | 1.3 |
| H4 | 16px | 500 Medium | 1.4 |
| Body Large | 16px | 400 Regular | 1.6 |
| Body Medium | 14px | 400 Regular | 1.6 |
| Body Small | 13px | 400 Regular | 1.6 |
| Caption | 11px | 400 Regular | 1.4 |

Expose these as composed utility classes (e.g. `.text-h1` … `.text-caption`) in a `@layer components` block so a heading is styled with one class and size/weight/line-height can never drift apart at call sites. Raw `text-[32px] font-bold leading-[1.2]` triples in components are not acceptable.

**Spacing** — 4px base unit, scale `4, 8, 16, 24, 32, 40, 64`. Tailwind v4's default 4px-step spacing already covers these (`p-1 p-2 p-4 p-6 p-8 p-10 p-16`); use those utilities rather than arbitrary values, and do not introduce off-scale spacing (no `p-3`, `p-5`, `p-7`, no `p-[18px]`).

**Grid** — container max-width `1280px`, 12 columns, gutter `24px`, outer margin `24px`. Provide one reusable container primitive (a `.container-biasly` class or a small `<Container>` component) applying `max-w-[1280px] mx-auto px-6`; every page uses it instead of re-deriving the width.

**Shadows**

| Token | Value |
|---|---|
| `--shadow-sm` | `0 1px 2px rgba(0,0,0,0.05)` |
| `--shadow-md` | `0 4px 12px rgba(0,0,0,0.08)` |
| `--shadow-lg` | `0 12px 24px rgba(0,0,0,0.12)` |

**Border radius**

| Token | Value |
|---|---|
| `--radius-sm` | `4px` |
| `--radius-md` | `8px` |
| `--radius-lg` | `12px` |
| `--radius-full` | `9999px` |

### 3. Components

All components are **server components by default**. Do not add `"use client"` unless a component genuinely needs interactivity — none in this task does. Every component takes explicit typed props; no `any`. Extend the correct native element props (e.g. `React.ComponentProps<"button">`) rather than inventing prop bags.

**`Logo`** — `biasly` in Poppins Bold with tight negative tracking, `News` in SemiBold on the line below, right-aligned to the wordmark. Props: `size` (`sm` | `md` | `lg`) and an `inverted` boolean for the dark footer treatment on the sheet (white text on `#0D0D0F`).

**`Button`** — restyle the shadcn variants to the sheet's matrix:

| Variant | Default | Hover | Disabled |
|---|---|---|---|
| Primary | `bg-text-primary`, white label, `rounded-md` | pure `#000`, `shadow-sm` | `bg-bg-secondary`, `text-secondary` at reduced opacity, `cursor-not-allowed` |
| Secondary | white bg, `border-border`, `text-primary` label | `bg-surface` | as above, muted border |
| Outline | white bg, `border-border` (`1px`), `text-primary` label | `bg-surface` | as above |
| Text | no bg, no border, `text-primary` label | label turns `text-bias-right` (`#1D4ED8`) | as above |

Per the sheet, Text has no outline or disabled cell (shown as `—`); implement `disabled` sensibly anyway since it is a native button state, but the root page renders those cells as an em dash. All variants: Poppins Medium, `14px`, `rounded-md` (8px), horizontal padding `16px`, height `40px`, a visible `focus-visible` ring using `--color-text-primary`, and a `transition-colors` on hover.

**`Chip`** — pill (`rounded-full`), `bg-surface`, `1px border-border`, `text-primary` label at Body Small (13px), trailing `Plus` lucide icon at `14px`, horizontal padding `12px`, height `32px`, `8px` gap between label and icon. Props: `label`, optional `onSelect`-free static rendering (it is presentational here), and `asChild`-free simplicity.

**`BiasMeter`** — the core biasly primitive. Props: `{ left: number; center: number; right: number; variant?: "full" | "compact" }`.
- A single horizontal bar, `rounded-sm` (4px), `overflow-hidden`, no gaps between segments.
- Three flex segments whose widths are the percentages: left `bg-bias-left` with white label, center `bg-bias-center` with `text-primary` label, right `bg-bias-right` with white label.
- Segment labels read `Left {n}%`, `Center {n}%`, `Right {n}%`, centered, Caption size, Medium weight.
- `full` variant: bar height `32px`, plus a scale row beneath showing `0%` / `50%` / `100%` in Caption `text-secondary`, aligned left / center / right.
- `compact` variant (used inside the card): bar height `22px`, no scale row.
- **Validate the props**: the three values must each be `0–100` and must sum to `100`, mirroring AGENTS.md section 19. If they do not, clamp/normalize defensively rather than rendering a broken bar — do not throw in a render path.
- Labels must not wrap or overflow when a segment is narrow; clip gracefully.

**`ArticleCard`** — reproduce the CARD EXAMPLE panel. Props: `{ title, description, category, country, imageUrl, imageAlt, publishedLabel, readTimeLabel, bias: { left, center, right } }`. No data fetching, no Supabase import — it receives already-stored data as props (AGENTS.md section 5: UI displays stored data only).
- Card: white bg, `1px border-border`, `rounded-lg` (12px), `shadow-sm`, padding `16px`.
- Two-column layout at `md` and up: image on the left at a fixed ~`208px` width, content column to the right, `24px` gap.
- Image: `rounded-md` (8px), `object-cover`, fills its box, uses `next/image` with explicit `width`/`height` (or `fill` inside a sized relative wrapper). A small circular `Info` icon badge sits at the image's top-right corner, white background, `shadow-sm`.
- Content column, top to bottom with `8px` rhythm: eyebrow `Politics · United States` (Caption, `text-secondary`, middot separator) → title at H3 (20px SemiBold, 1.3) clamped to two lines → description at Body Medium `text-secondary` clamped to two lines → `BiasMeter` in `compact` → footer row.
- Footer row: `Clock` icon + `publishedLabel`, then `Bookmark` icon + `readTimeLabel`, both Body Small `text-secondary`, icons `16px`, `24px` gap between the two groups, `6px` gap between each icon and its text.

**Icons** — a thin `components/ui/icon.tsx` wrapper is optional; if added it fixes `strokeWidth={2}` and a default `size`. Do not re-implement lucide icons by hand or paste raw SVG paths.

### 4. Root route

`app/page.tsx`, a server component, reproducing the reference sheet panel by panel on a `#F0F0F0` page background, using the container primitive. Panels, in the sheet's order:

1. **BRAND** — logo lockup + tagline `Balanced news coverage, powered by AI.`
2. **COLORS** — three groups (PRIMARY / SEMANTIC / NEUTRALS) as swatch tiles, each showing the swatch, the uppercase token name, and its hex. Swatches for white and near-white values carry a border so they remain visible.
3. **TYPOGRAPHY** — the font-family blurb plus a table with columns STYLE / example / SIZE / WEIGHT / LINE HEIGHT, each row rendered in its own actual style.
4. **UI ELEMENTS** — the BUTTONS matrix (rows Primary / Secondary / Text × columns Default / Hover / Outline / Disabled; the Hover column renders the hover appearance statically so it is visible without a pointer, and `—` where the sheet shows one), the CHIP / CATEGORY row (`World Cup`, `IPL`, `Business & Markets`, `More`), and the BIAS METER in `full` variant at 25/50/25.
5. **ICONS** — the 15 icons in a grid, with the caption `Line style · 2px stroke · Rounded caps`.
6. **CARD EXAMPLE** — one `ArticleCard` with the sheet's demo content and bias `25 / 26 / 49` (the sheet's card reads Left 25% / Center 50% / Right 49%, which cannot sum to 100; use `25 / 26 / 49` so the component's own sum rule holds, and note this in the delivery message).
7. **SPACING SYSTEM** — the `4 → 64` ramp as squares with labels, plus the caption `Consistent spacing scale based on 4px base unit`.
8. **GRID SYSTEM** — 12 column bars with the Container 1280px / Columns 12 / Gutter 24px / Margin 24px annotations.
9. **SHADOWS** — three white tiles demonstrating sm / md / lg with their CSS values printed.
10. **BORDER RADIUS** — four tiles demonstrating 4 / 8 / 12 / 9999px.
11. **Footer** — dark `#0D0D0F` bar: inverted logo, tagline, `Design System v1.0`, and `Stay consistent. Stay unbiased.`

Each panel is a white card: `rounded-lg`, `1px border-border`, `shadow-sm`, `24px` padding, with an uppercase Caption-weight panel title above a divider rule.

**Demo image**: the card needs a real image. Use a local file under `public/` (add one) or a remote URL — if remote, add the host to `images.remotePatterns` in `next.config.ts`. Prefer a local placeholder to avoid touching Next config for a dev-only page.

### 5. Visual interpretation and pixel-perfect expectations

- The root page is a **faithful reproduction of the sheet**, not a loose homage: the same panel order, the same grouping, the same labels and casing (`TEXT PRIMARY`, `BG SECONDARY`, `4px BASE UNIT`), the same hex strings printed under each swatch.
- Every hex, px, weight, line-height and shadow value above must appear **exactly** as specified. No rounding `#0D0D0F` to `#0D0D0D`, no substituting `#6B7280` with Tailwind's `gray-500`.
- Panel titles are uppercase with wide letter-spacing, matching the sheet.
- Typography must visibly differ row to row on the type-scale table — if H4 and Body Large (both 16px) look identical, the weight token is wrong (500 vs 400).
- Bias-meter segment widths must be visually proportional to their percentages.

### 6. Responsiveness

- Mobile-first. The sheet is a desktop artboard; the sheet reflows to a single column below `md`.
- `ArticleCard` stacks vertically below `md`: image full-width above the content, image height capped so it does not dominate the viewport.
- `BiasMeter` stays a single row at every breakpoint; only label sizes may shrink.
- No horizontal page scroll at 375px width in any panel — the grid, spacing ramp, and button matrix must scroll internally or wrap rather than widening the page.
- The container keeps its `24px` side margin at all widths.
